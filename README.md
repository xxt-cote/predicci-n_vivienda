# Predicción de precio de vivienda

Ejercicio de regresión lineal (scikit-learn) que predice el precio de una vivienda en
UF a partir de su superficie, número de habitaciones y distancia al metro.

## Uso

```bash
pip install pandas scikit-learn numpy
python "predecir precio de vivienda/vivienda.py"
```

## Nota

El dataset de ejemplo incluido en el script tiene solo 5 observaciones, por lo que las
métricas (R², RMSE) reflejan un ajuste sobre una muestra muy pequeña y son solo
ilustrativas del flujo de trabajo, no de un modelo listo para producción.
